============================================================
  A) TAM KURULUM (Backend + Frontend + DB — Docker)
============================================================

  1. Docker Desktop'in acik oldugundan emin ol.

  2. Proje kokune git:

       cd "c:\Users\Taha\Projects\docker_version"

  3. Docker container'lari baslat:

       docker compose up -d

     Bu komut 4 servis ayaga kaldirir:
       - backend  (Django, port 8000)
       - frontend (Vite,   port 5173)
       - db       (PostgreSQL, port 5432)
       - redis    (port 6379)

     Ilk calistirmada migrate + seed_factory otomatik calisir.

  4. API testi (401 donmesi = calisiyor demek):

       curl http://localhost:8000/api/live/overview/

  5. Tarayicidan ac:

       http://localhost:5173

============================================================
  B) SADECE FRONTEND (Mock Data — Backend Gerektirmez)
============================================================

  Backend'i ayaga kaldirmadan sadece frontend'i mock
  verileriyle calistirmak icin:

  1. Frontend .env dosyasini duzenle:

       Dosya: mes-frontend/mes-frontend/.env

       Icerigi:
         VITE_API_MODE=mock
         VITE_API_BASE_URL=/api

  2. Terminalde frontend klasorune git:

       cd "c:\Users\Taha\Projects\docker_version\mes-frontend\mes-frontend"

  3. Bagimliliklari kur (ilk seferde veya package.json degistiginde):

       npm install

  4. Dev sunucusunu baslat:

       npx vite --host

  5. Cikti soyle gorunecek:

       VITE v6.4.1  ready in 400 ms
         Local:   http://localhost:5173/
         Network: http://192.168.x.x:5173/

  6. Tarayicidan ac:

       http://localhost:5173

  NOT: Mock modda tum sayfalar (Dashboard, Production, Work Orders,
  Live Map) simule edilmis verilerle calisir. Login gerekmez;
  herhangi bir kullanici adi/sifre ile giris yapilabilir.

============================================================
  C) SADECE BACKEND (Gercek API)
============================================================

  Frontend'i mock yerine gercek backend'e baglamak icin:

  1. Frontend .env dosyasini su sekilde ayarla:

       VITE_API_MODE=real
       VITE_API_BASE_URL=/api

  2. docker compose up -d   ile backend'i baslat.

  3. Frontend'i baslat (B bolumundeki adimlari takip et).

============================================================
  FAYDALI KOMUTLAR
============================================================

  Backend loglarini gor:
    docker compose logs -f backend

  Migration uygula:
    docker compose exec backend python manage.py migrate

  Django shell:
    docker compose exec backend python manage.py shell

  Veritabanini yeniden doldur:
    docker compose exec backend python manage.py seed_factory

  Yeni kullanici olustur:
    docker compose exec backend python manage.py createsuperuser

  Telemetri simulasyonu baslat:
    docker compose exec -d backend python manage.py simulate_telemetry --machine cnc-001 --interval 2

  TypeScript tip kontrolu (frontend):
    cd mes-frontend/mes-frontend
    npx tsc --noEmit
