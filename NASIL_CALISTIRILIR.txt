  - Node.js (v18+)
  - Git Bash veya terminal (PowerShell / CMD de olur)

============================================================
  A) TAM KURULUM (Backend + Frontend + DB — Docker)
============================================================

  1. Docker Desktop'in acik oldugundan emin ol.

  2. Proje kokune git:

       cd "c:\Users\Taha\Projects\TRACE-MES"

  3. Docker container'lari baslat:

       docker compose up -d

     Bu komut 4 servis ayaga kaldirir:
       - backend  (Django, port 8000)
       - frontend (Vite,   port 5173)
       - db       (PostgreSQL, port 5432)
       - redis    (port 6379)

     Ilk calistirmada migrate + seed_factory otomatik calisir.

  4. API testi (401 donmesi = calisiyor demek):

       curl http://localhost:8000/api/live/overview/

  5. Tarayicidan ac:

       http://localhost:5173

============================================================
  B) SADECE FRONTEND (Mock Data — Backend Gerektirmez)
============================================================

  Backend'i ayaga kaldirmadan sadece frontend'i mock
  verileriyle calistirmak icin:

  1. Frontend .env dosyasini duzenle:

       Dosya: mes-frontend/mes-frontend/.env

       Icerigi:
         VITE_API_MODE=mock
         VITE_API_BASE_URL=/api

  2. Terminalde frontend klasorune git:

       cd "c:\Users\Taha\Projects\docker_version\mes-frontend\mes-frontend"

  3. Bagimliliklari kur (ilk seferde veya package.json degistiginde):

       npm install

  4. Dev sunucusunu baslat:

       npx vite --host

  5. Cikti soyle gorunecek:

       VITE v6.4.1  ready in 400 ms
         Local:   http://localhost:5173/
         Network: http://192.168.x.x:5173/

  6. Tarayicidan ac:

       http://localhost:5173

  NOT: Mock modda tum sayfalar (Dashboard, Production, Work Orders,
  Live Map) simule edilmis verilerle calisir. Login gerekmez;
  herhangi bir kullanici adi/sifre ile giris yapilabilir.

============================================================
  C) SADECE BACKEND (Gercek API)
============================================================

  Frontend'i mock yerine gercek backend'e baglamak icin:

  1. Frontend .env dosyasini su sekilde ayarla:

       VITE_API_MODE=real
       VITE_API_BASE_URL=/api

  2. docker compose up -d   ile backend'i baslat.

  3. Frontend'i baslat (B bolumundeki adimlari takip et).

============================================================
  D) MAKINE SIMULATORU GUI (Tkinter — Masaustu)
============================================================

  Ne ise yarar:
    Makine ekle/sil, program (is emri) baslat/durakla/devam/durdur,
    canli telemetri + olay gunlugunu masaustu penceresinde gor.
    Bu bir DESKTOP penceresidir; headless/SSH ile calismaz, ekran
    (X11/Wayland veya Windows masaustu) gerekir.

  --- ON KOSULLAR (her iki OS) ---

    1. Veritabani ayakta olmali. En kolayi docker ile:
         docker compose up -d db          (ya da tum sistem: up -d)
       Bu, PostgreSQL'i  localhost:5432  uzerinde yayinlar.

    2. GUI HOST uzerinde (container DISILINDA) calisir; cunku Tkinter
       ekran ister. Bu yuzden DB'ye 'db' yerine 'localhost' ile baglanir
       -> komuttan once  SQL_HOST=localhost  vermek SART.
       (Sebep: .env icinde SQL_HOST=db yazar; bu ad yalnizca docker agi
        icinde cozulur. manage.py .env'i override etmeden yukler, yani
        kabukta verilen SQL_HOST kazanir.)

  ------------------------------------------------------------
    WINDOWS  (PowerShell)
  ------------------------------------------------------------

    cd C:\Users\<kullanici>\Projects\TRACE-MES\backend

    # ilk seferde: sanal ortam + bagimliliklar
    python -m venv .venv
    .venv\Scripts\python.exe -m pip install -r requirements.txt
    # (Tkinter, python.org Windows kurulumuyla hazir gelir)

    # her calistirma:
    $env:SQL_HOST="localhost"
    .venv\Scripts\python.exe manage.py simulator_gui

  ------------------------------------------------------------
    LINUX / macOS  (bash)
  ------------------------------------------------------------

    cd ~/Projects/github/TRACE-MES/backend

    # ilk seferde: Tkinter sistem paketi (Debian/Ubuntu/Parrot)
    sudo apt install -y python3-tk python3-venv
    #   Fedora:  sudo dnf install python3-tkinter
    #   macOS :  brew install python-tk

    # ilk seferde: sanal ortam + bagimliliklar
    python3 -m venv .venv
    .venv/bin/python -m pip install -r requirements.txt

    # her calistirma (tek satir):
    SQL_HOST=localhost .venv/bin/python manage.py simulator_gui

  --- SECENEKLER ---
    --interval <sn>   Tick araligi (varsayilan 1.0sn). Orn:
       SQL_HOST=localhost .venv/bin/python manage.py simulator_gui --interval 0.5

  --- NOT: run_live_generator ILE BIRLIKTE CALISTIRMA ---
    Hem simulator_gui hem run_live_generator, RUNNING makineler icin
    telemetri uretir. IKISINI AYNI ANDA calistirma -> cift telemetri olur.
    - Makineleri ELLE yonetmek (program baslat/durdur) istiyorsan: GUI kullan.
    - Arka planda otomatik veri akisi istiyorsan: run_live_generator kullan.
    GUI'yi acmadan once generator calisiyorsa once onu durdur.

============================================================
  FAYDALI KOMUTLAR
============================================================

  Backend loglarini gor:
    docker compose logs -f backend

  Migration uygula:
    docker compose exec backend python manage.py migrate

  Django shell:
    docker compose exec backend python manage.py shell

  Veritabanini yeniden doldur:
    docker compose exec backend python manage.py seed_factory

  Yeni kullanici olustur:
    docker compose exec backend python manage.py createsuperuser

  Telemetri simulasyonu baslat:
    docker compose exec -d backend python manage.py simulate_telemetry --machine cnc-001 --interval 2

  TypeScript tip kontrolu (frontend):
    cd mes-frontend/mes-frontend
    npx tsc --noEmit
